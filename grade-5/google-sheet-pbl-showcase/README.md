# Google Sheet PBL Showcase

Static upload package for Netlify Drop.

## Deploy to Netlify

1. Go to <https://app.netlify.com/drop>
2. Upload this folder or upload `google-sheet-pbl-showcase.zip`
3. Wait for Netlify to publish the site
4. Open the generated `https://...netlify.app` URL and confirm the page loads at the site root

## Files

- `index.html` is the site entry point
- Upload the folder or ZIP exactly as-is so `index.html` stays at the site root

## Notes

- No build step is required
- This is a static HTML page and can be hosted directly
