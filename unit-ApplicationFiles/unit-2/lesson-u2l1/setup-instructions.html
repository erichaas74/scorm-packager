Buzz Setup: Unit 2 Lesson 1 PhET Projectile Launch Lab

Step 1: Confirm the PhET link

  1. Use the direct PhET simulation link: https://phet.colorado.edu/sims/html/projectile-motion/latest/projectile-motion_all.html.
  2. The Buzz template embeds the simulation and also includes an external launch button.
  3. Preview in Buzz. If the iframe does not load, students can still use the launch button.

Step 2: Create the Buzz assessment questions

  1. Create a Buzz Assessment titled Unit 2 Lesson 1: PhET Projectile Launch Lab.
  2. Open buzz-assessment-questions.txt and paste the full contents into the Buzz Assessment text editor or Edit all questions screen.
  3. The file is formatted with Buzz text-import syntax and contains thirteen scored questions.
  4. Keep the questions in the exact order shown. Each <a:question></a:question> slot pulls in the next Buzz question.
  5. The walkthrough uses Part A horizontal-launch trials and Part B maximum-height comparison trials.

Step 3: Upload the Buzz template

  1. Upload u2l1-phet-projectile-buzz-assessment-template.html as the assessment template in Buzz.
  2. Preview as a student and confirm the PhET launch area, directions, and thirteen native Buzz questions appear.
  3. No SCORM zip is needed for this version. The old Unit 2 Lesson 1 Crosswind zip was removed.
