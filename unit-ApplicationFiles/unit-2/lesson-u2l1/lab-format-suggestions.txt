Lab Format Suggestions: Unit 2 Lesson 1 - PhET Projectile Launch Lab

Current format
- This lesson now uses PhET Projectile Motion as the hosted/linked simulation source.
- The assessment is now a guided walkthrough template with thirteen scored Buzz questions.
- Part A tests horizontal launches from the same 12 m height at 0, 5, 10, and 20 m/s.
- Part B compares maximum height for 90 degrees / 13 m/s, 60 degrees / 15 m/s, and 30 degrees / 26 m/s.
- Buzz owns the assessment questions and scoring.
- No SCORM zip is needed for the current Buzz-native version.

Recommended Buzz workflow
1. Paste the full contents of buzz-assessment-questions.txt into the Buzz Assessment text editor or Edit all questions screen.
2. Upload buzz-assessment-template-for-buzz.html as the Buzz assessment template.
3. Keep the PhET link visible in the directions: https://phet.colorado.edu/en/simulations/projectile-motion
4. Use the embedded PhET sim if Buzz allows it, and keep the external launch button as the fallback.
5. Preview that all thirteen Buzz question slots render in order below the PhET directions.
6. Verify the numeric tolerance ranges in the Fill in the Blank questions with the current PhET simulation.
