4) Use Level 1 to explain how the swimmer velocity vector and river velocity vector combine to make the swimmer's path across the river.
A

A strong answer explains that the swimmer velocity and river current add as vectors. The swim heading controls the swimmer vector, the current adds downstream velocity, and the resultant ground velocity determines the actual path.

7) Explain why changing the heading in Level 2 changes the path even though the swimmer speed and river speed stay fixed.
A

A strong answer explains that changing heading rotates the swimmer velocity vector. The current vector is still added to that new swimmer vector, so the resultant path shifts and can miss the logs.
