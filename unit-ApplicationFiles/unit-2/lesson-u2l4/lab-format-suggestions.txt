Lab Format Suggestions: Unit 2 Lesson 4 - River Rescue

Current fit for the new Buzz format
- Good interactive lab, but the open-ended sliders mean there is not one fixed numeric answer key.
- It already tracks SCORM progress by level, but the new format needs clear values students can submit in Buzz.

Suggested changes before converting the lab page
1. Add a Lab Report panel that stores completed telemetry for each level:
   - level number
   - swim speed
   - heading
   - river speed
   - river width
   - final time
   - ground speed
   - downstream drift
   - stamina left
   - stars/rating
2. Add a "Download Lab Report Image" button for Buzz upload.
3. Add a "Copy values for Buzz" button to reduce transcription errors.
4. Add a fixed "Buzz challenge mode" if you want numeric auto-grading. For example, lock river width and current speed, then ask for a heading or resultant velocity.
5. Add a final message after Level 4 success: "Return to Buzz and answer the assessment questions."
6. Consider preserving the student's completed level report even after switching levels or resetting, so evidence is not lost.
7. Replace the Tailwind CDN dependency with built CSS or a local stylesheet before hosting if the school/Buzz environment blocks CDN scripts.
8. If Buzz owns grading, keep SCORM progress as optional telemetry only and do not rely on it as the grade.
