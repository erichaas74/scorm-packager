Buzz Setup: Unit 2 Lesson 5 Inertia and Tension Demo

Step 1: Create the Buzz questions

  1. Create a Buzz Assessment titled Unit 2 Lesson 5: Inertia and Tension Demo.
  2. Open buzz-assessment-questions.txt and paste the full contents into the Buzz Assessment text editor or Edit all questions screen.
  3. The file contains eleven scored questions: Level 1 cup/card/penny observations, Level 2 string observations, fixed tension values, inertia explanations, and evidence upload.
  4. Keep the questions in the exact order shown. Each <a:question></a:question> slot pulls in the next Buzz question.

Step 2: Upload the self-contained template

  1. Upload buzz-assessment-template-for-buzz.html as the assessment template in Buzz.
  2. The template contains the inertia demo directly, so inertia-tension-demo.html does not need to be uploaded as a separate Buzz resource.
  3. Preview as a student and confirm the stage bar switches between Level 1 and Level 2, and that the Slow Pull and Fast Pull buttons work in both stages above the native Buzz questions.
