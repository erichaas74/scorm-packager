Lab Format Suggestions: Unit 2 Honors Project - Coriolis Cannon Challenge

Current fit for the new Buzz format
- Good visual exploration lab, but it needs a clearer data log for Buzz submission.
- The current controls are flexible, so answers vary unless fixed presets are added.
- The 3D globe depends on external CDN assets that may be blocked in some school/Buzz environments.

Suggested changes before converting the lab page
1. Add a Trial Log panel that records each fire event:
   - aim correction
   - shell speed
   - target distance
   - rotation rate
   - latitude
   - hemisphere
   - hit/miss
   - miss distance
2. Add named Buzz presets such as "Direct Aim", "Corrected Aim", "Short Distance", "Long Distance", and "Hemisphere Compare."
3. Add a "Download Evidence Image" button for the trial log and current canvas.
4. Add a "Copy values for Buzz" button after a hit.
5. Add a clearer miss-side label, not only miss distance, so students can answer left/right or north/south questions accurately.
6. Add a final instruction after a successful hit: "Return to Buzz and answer the assessment questions."
7. Package the Globe.gl/Three.js dependencies locally or add a simple fallback if CDN loading fails.
8. If Buzz should auto-grade numeric values, lock the relevant sliders for each preset so all students produce the same expected answers.
