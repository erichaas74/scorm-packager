Buzz Setup: Projectile Launch Lab

Step 1: Use the built-in lab support panel

  1. The Buzz template includes a visual ball-flight lab scene, timing/measuring reminders, and a Use Simulated Data button.
  2. Students should collect real distance and time data if they can safely do the throw at home.
  3. If they cannot complete the real throw, they can click Use Simulated Data, record the generated distance and time, and upload a screenshot of that panel as evidence.
  4. No separate baseball-throw.html resource is required for the Buzz template version. The same HTML is also available as index.html for local lesson-page testing.

Step 2: Create the Buzz questions

  1. Create a Buzz Assessment titled Projectile Launch Lab: Finding Launch Velocity.
  2. Open buzz-assessment-questions.txt and paste the full contents into the Buzz Assessment text editor or Edit all questions screen.
  3. The file is formatted with Buzz text-import syntax: every question starts with Type:, uses Score:, and separates questions with a blank line.
  4. Keep them in the exact order shown. Each <a:question></a:question> slot pulls in the next Buzz question.

Step 3: Upload the Buzz template

  1. Upload buzz-assessment-template-for-buzz.html as the assessment template in Buzz.
  2. Preview as a student and confirm the visual lab scene, simulated data button, directions, and ten native Buzz questions appear.
