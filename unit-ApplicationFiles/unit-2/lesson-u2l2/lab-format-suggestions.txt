Lab Format Suggestions: Unit 2 Lesson 2 - Projectile Launch Lab: Finding Launch Velocity

Current fit for the new Buzz format
- Strong fit for a Buzz-owned assessment because every student can collect a real throw and complete calculations in Buzz.
- Student answers will vary because distance and time are measured from an individual launch.
- The existing baseball-throw.html tool can support the calculation workflow, but the new student template is written as a real-world launch lab.
- The Buzz template now includes an embedded ball-flight visual with a timer, distance measurer, and simulated data button for students who cannot safely complete the real throw at home.
- index.html now contains the same self-contained ball-flight HTML for local lesson-page testing.

Suggested changes before publishing
1. Use the Buzz template and questions so students submit measured data, calculations, and a conclusion in Buzz.
2. Keep calculation questions as Short Answer or Essay unless the teacher manually sets individual tolerances.
3. Require distance in meters and time in seconds before students calculate any velocities.
4. Add a reminder that students should divide total flight time by 2 when calculating initial vertical velocity with vy = 9.8 x t / 2.
5. Have students who use simulated data record the generated distance and time before beginning the calculations.
6. If using baseball-throw.html as an optional hosted lab tool, hide or teacher-lock the Answer Key Preview before students use it.
7. Add a final instruction: "Return to Buzz and enter your data, calculations, and conclusion."
