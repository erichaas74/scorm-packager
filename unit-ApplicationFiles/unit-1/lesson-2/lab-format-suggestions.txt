Lab Format Notes: Unit 1 Lesson 2 - City Blocks Challenge

Status: SCORM activity plus self-contained Buzz-native assessment (July 2026).

Current design
1. Time mechanic: every block moved takes 1 minute, and a WAIT button
   passes 1 minute at a stoplight without moving. This makes average speed
   (distance / time) and average velocity (displacement / time, with a
   compass direction) real, computable quantities in the sim.
2. Unified HUD dashboard over the canvas: Level and Time in the header,
   then TARGETS and CURRENT columns side by side. The D-pad (with WAIT in
   the center) sits below the dashboard, then Undo/Reset, with the map Key
   pinned to the bottom. Live speed/velocity readouts show only on the
   levels that target them.
3. 6 levels, each with exactly two targets:
   - Levels 1-3: distance + displacement.
   - Levels 4-5: distance + average speed (forces strategic waiting).
   - Level 6: displacement + average velocity.
4. Passing = building a route that matches both targets. There are no
   built-in quiz questions. A level dropdown lets students play in any
   order and marks each level with ○ (not passed) or ✓ (passed).
5. The original SCORM version reports a 0-6 score. The Buzz-native version
   uses 11 assessment points plus a required evidence upload.
6. The Buzz template includes six native question slots, a dynamic evidence
   report, a Download Evidence Image button, and a Copy Values for Buzz button.
7. The Unit 1 branch page labels this folder as City Blocks Challenge and
   the lesson-1-additions folder as the alternate Motion Graphs build.

Remaining ideas (optional, not required for Buzz)
