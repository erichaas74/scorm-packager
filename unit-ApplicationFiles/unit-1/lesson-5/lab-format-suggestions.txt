Lab Format Suggestions: Unit 1 Lesson 5 - Skydiver Graphs and BASE Jump Speed Run

Status: Self-contained Buzz-native assessment with a fixed scripted graph section and a student-dependent BASE jump speed-run section.

Current fit for the new Buzz format
- Part 1 is a scripted jump with fixed graph values. This is a good fit for native Buzz questions because every student sees the same velocity-time and acceleration-time graphs.
- Part 2 is a student speed run. Students choose body position and parachute timing to minimize final time while landing at 8 m/s or slower, so those answers are student-dependent and should be graded with evidence plus written explanation.
- The speed run is successful when the student deploys the parachute and lands at 8 m/s or slower.
- The template includes Download Challenge Evidence and Copy Challenge Results controls.
- Do not turn the challenge results into fixed-answer Buzz numeric questions unless the challenge is locked to a single scripted outcome.

Current files
- sky-dive-lab.html: standalone local version of the scripted jump and challenge.
- buzz-assessment-questions.txt: import-ready Buzz text with five fixed graph questions, one upload question, and one speed-run strategy essay.
- u1l5-skydiver-buzz-assessment-template.html: generic backup copy of the self-contained Buzz template.
- u1l5-skydiver-buzz-assessment-template.html: lesson-specific Buzz upload template. Use this file for Buzz.
- u1l5-skydiver-buzz-assessment-template-preview.html: local preview wrapper.
- busybee-rubric-metadata.json: BusyBee grading metadata for the challenge evidence and written strategy.
- index.html: local redirect to sky-dive-lab.html.

Buzz setup
1. Paste buzz-assessment-questions.txt into the Buzz assessment text editor or Edit all questions screen.
2. Upload u1l5-skydiver-buzz-assessment-template.html as the assessment template.
3. Turn off randomized question order.
4. Do not use one-question-per-page.
5. Preview the scripted jump graphs and confirm the five graph questions appear after Part 1.
6. Complete a BASE jump speed run and confirm the evidence upload and strategy questions appear after Part 2.

Remaining work before publishing
- Preview in Buzz and confirm the template script runs inside the assessment frame.
- Confirm Download Challenge Evidence works in the student browser.
- Confirm BusyBee can read the uploaded evidence for Q6, the strategy explanation for Q7, and busybee-rubric-metadata.json if you use the external rubric file.
