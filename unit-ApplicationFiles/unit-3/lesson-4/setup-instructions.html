Buzz Setup: Unit 3 Lesson 4 Collision Lab

What this activity is

The assessment template is a HTML/CSS-only page styled like a lab data chart. Each chart cell contains a real Buzz question placeholder (<a:question />): Questions 1–4 are numeric-input questions for the Trial 1 momentum and kinetic-energy totals, and Question 5 is the analysis question. The simulator itself (collison-lab.html) is a separate hosted page students open from a button in the template — it contains no data chart, learning goals, or evidence panel anymore; those live in the template only.

Every trial has fixed initial conditions — there are no mass or speed controls, so all students collect identical data and the numeric questions grade cleanly. Trial 1: m₁ = 1.0 kg moving right at 3.0 m/s, m₂ = 2.0 kg at rest, elasticity 100%. The simulator shows each trial's setup in a chip bar above the readouts, and students use the trials to prove conservation of momentum and examine when kinetic energy is conserved.

Sign convention is a graded skill: the simulator never displays + or − signs. Every velocity/momentum readout shows a magnitude with a direction arrow (after the Trial 1 run: v₁′ = 1.00 m/s ← and v₂′ = 2.00 m/s →). Students must convert arrows to signs themselves (right = +, left = −) before calculating the momentum totals, so a wrong sign on Question 3 usually means they skipped that step.

Step 1: Host the simulator and set the link

  1. Host collison-lab.html on your web server (or upload it as a Buzz resource and copy its URL).
  2. In buzz-assessment-template-for-buzz.html, replace REPLACE-WITH-HOSTED-COLLISION-LAB-URL with that URL. The marker appears once, on the "Open the Collision Lab Simulator" button.

Step 2: Create the Buzz questions

  1. Create a Buzz Assessment titled Unit 3 Lesson 4: Collision Lab - Elastic and Inelastic Collisions.
  2. Open buzz-assessment-questions.txt and create the five questions in that exact order: Questions 1–4 as separate numeric-input questions, Question 5 as an essay/analysis question.
  3. Answer key: Q1 = +3.00 kg·m/s, Q2 = 4.50 J, Q3 = +3.00 kg·m/s, Q4 = 4.50 J (ranges in the file allow rounding). Q5 grading guide is included in the file.

Step 3: Upload the template

  1. Upload buzz-assessment-template-for-buzz.html as the assessment template.
  2. The template has five <a:question /> slots; Buzz fills them with your five questions in order, so the question order must match the slot order.
  3. Open buzz-assessment-template-preview.html locally first to see where each question lands.

Important: do NOT set the assessment to show one question per page. At least Questions 1–4 must appear on the same page so they read as a single data chart.

Step 4: Preview as a student

  1. Confirm the four chart cells render side by side (2×2) on desktop and stack on a narrow window.
  2. Confirm each cell shows its own numeric answer box and Question 5 shows the essay box.
  3. Click the simulator button and verify the hosted lab opens, Trial 1's setup bar shows the fixed conditions (Ball 1: 1.0 kg, 3.00 m/s →; Ball 2: 2.0 kg, at rest; Elasticity: 100%), and after Run Collision the readouts above the canvas show 1.00 m/s ← and 2.00 m/s → (magnitudes with arrows, no signs).
  4. Enter 3, 4.5, 3, 4.5 and confirm all four numeric questions grade correct.
