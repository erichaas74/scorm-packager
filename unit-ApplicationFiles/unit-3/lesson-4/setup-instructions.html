Buzz Setup: Unit 3 Lesson 4 Collision Lab

What this activity is

A self-contained 1D collision simulator that replaces the PhET Collision Lab worksheet. Students complete the worksheet's four trials inside the lab: the sim records their masses and initial velocities, and students fill in the final velocities plus the momentum and kinetic energy totals they calculate by hand. The lab checks each chart box (green check / red X) without ever revealing the correct value. Before/after momentum-vector sketches are captured automatically, replacing the hand-drawn sketch boxes. An Explore: 50% Elasticity tab supports the hypothesis-testing question.

Step 1: Create the Buzz questions

  1. Create a Buzz Assessment titled Unit 3 Lesson 4: Collision Lab - Elastic and Inelastic Collisions.
  2. Open buzz-assessment-questions.txt and paste the full contents into the Buzz Assessment text editor / Edit all questions screen.
  3. The file contains ten questions worth 15 points total: five multiple choice, four essay analysis questions from the worksheet, and one evidence-image upload.
  4. Keep the questions in the exact order shown. Each <a:question></a:question> slot in the template pulls in the next Buzz question.

Step 2: Upload the self-contained template

  1. Upload buzz-assessment-template-for-buzz.html as the assessment template in Buzz.
  2. The template contains the collision simulator directly, so collison-lab.html does not need to be uploaded as a separate Buzz resource. (That file is the standalone hosted version with a Back to Unit 3 link, for use outside Buzz.)
  3. Open buzz-assessment-template-preview.html locally first to see where each Buzz question will appear.

Step 3: Preview as a student

  1. Confirm the five tabs switch (Trials 1-4 plus Explore) and Run Collision animates with momentum arrows.
  2. Run Trial 1, fill the chart with correct values, and confirm Check My Chart turns the boxes green and the tab shows a check mark. Enter one wrong value and confirm the box turns red without showing the correct answer.
  3. Confirm Download Evidence Image saves collision-lab-evidence.png and Copy Values for Buzz fills the clipboard.
  4. Trial charts save to the browser's local storage, so a page refresh keeps student progress on the same device. There is no SCORM tracking - Buzz owns the grade through the questions.

Grading notes

  • Student data varies by design (they choose masses and velocities), so the essay questions ask them to cite their own before/after totals; the uploaded evidence image is how you verify those numbers.
  • The evidence image marks each trial chart complete only if every chart box was verified correct, so a complete image is itself proof of correct momentum/KE calculations.
  • Chart tolerance: final velocities within 0.05 m/s of the readout; totals within 2% (minimum 0.15) to absorb rounding of displayed velocities.
