Buzz Setup: Unit 3 Lesson 5 Impulse Jump Lab

What this activity is

The Buzz template is a self-contained impulse jump simulation. Students run an animated jumper while a required net force-time graph fills in. The graph is fixed for grading: mass = 75 kg, g = 9.81 m/s^2, peak net force = 1500 N, and contact time = 0.40 s.

The eight Buzz question slots walk students through the calculation chain: read push time, read peak force, find average force, determine impulse, identify change in momentum, calculate takeoff velocity, calculate maximum height, and explain the full impulse chain.

Step 1: Create the eight Buzz questions

  1. Create a Buzz Assessment titled Unit 3 Lesson 5: Impulse Jump Lab.
  2. Open buzz-assessment-questions.txt and paste the question blocks into the Buzz Assessment text editor / Edit all questions screen.
  3. Keep the questions in the exact order shown. The template has eight <a:question></a:question> placeholders, and Buzz fills them from top to bottom.

Step 2: Upload the template

  1. Upload u3l5-impulse-jump-buzz-assessment-template.html as the assessment template.
  2. Open u3l5-impulse-jump-buzz-assessment-template-preview.html locally first to confirm where each question lands.
  3. Preview as a student in Buzz and press Run Jump. Confirm the animated jumper and graph draw correctly.

Turn OFF randomize/shuffle question order in Buzz. Also do not use one question per page. The template depends on the eight questions staying in order so each slot matches its step.
