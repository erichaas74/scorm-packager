Lab Format Suggestions: Unit 3 Lesson 5 - Impulse Jump Lab

Current fit for the new Buzz format
- Strong fit for Buzz because the lab already guides students through a calculation ladder.
- The current lab lets students choose any profile, so fixed Buzz grading needs a required profile or a report that names the profile clearly.

Suggested changes before converting the lab page
1. Add a locked "Buzz required trial" mode for Athletic Max Jump, or let the teacher select the required profile in the directions.
2. Add a Lab Evidence panel that lists:
   - profile name
   - push time
   - average net force
   - impulse
   - takeoff velocity
   - max height
3. Add a "Download Evidence Image" button for the graph plus calculation history.
4. Add a "Copy values for Buzz" button after the five calculation steps are complete.
5. Add a comparison table for Quick Hop, Deep Squat Jump, and Athletic Max Jump so students can support the reflection question with data.
6. If Buzz is grading the calculations, consider changing the in-lab checker so it confirms attempts without immediately advancing after a wrong answer.
7. Add a final instruction after Step 5: "Return to Buzz and answer the assessment questions."
8. Package external dependencies locally if the hosted environment blocks CDN scripts or styles.
