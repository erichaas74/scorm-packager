Lab Format Suggestions: Unit 3 Lesson 2 - Newton's Spacewalk Momentum Choice Lab

Current fit for the new Buzz format
- Good fixed-answer lab for Buzz because the two missions and correct choices are built in.
- The current page is more of an interactive choice activity than a data notebook.

Suggested changes before converting the lab page
1. Remove or teacher-lock the "Show Answer" button for the student-facing hosted version.
2. Add a Mission Results panel that records for each level:
   - chosen object
   - object mass
   - throw speed
   - astronaut velocity after throw
   - arrival time
   - docking speed
   - success/failure result
3. Add a "Download Evidence Image" button for the Mission Results panel.
4. Add a "Copy values for Buzz" button after each successful mission.
5. Add explicit "Complete Level 1 and Level 2, then return to Buzz" directions.
6. Add SCORM or simple completion tracking if the hosted page still needs to show completion, but let Buzz own the grade.
7. Consider adding a third mission later if the assessment needs more data variety.
8. Clean up the text encoding in the file before publishing so symbols like arrows and dash characters render correctly in all browsers.
