Buzz Setup: Unit 3 Lesson 2 Golf Club CT Compliance Test

What this activity is

This is a self-contained, fixed-data pendulum impact investigation. The template preserves the original pendulum scene and force-time traces. Part 1 uses four calibration faces: Soft Polymer, Alloy, Thin Titanium, and Thick Titanium. Part 2 compares Rigid Steel with Prototype X-7 to determine which one is compliant with the CT limit.

Students record contact time, peak force, and average force for each test face in the 21 Buzz slots. Prototype X-7 is the fixed Profile B trace, which is closest to Alloy and has a non-conforming CT. The template does not display computed results.

Step 1: Create the assessment

  1. Use the title Unit 3 Lesson 2: USGA Golf Club CT Compliance Test.
  2. Paste all of buzz-assessment-questions.txt into Buzz's Text editor / Edit all questions screen.
  3. Confirm that Buzz creates 21 questions worth 21 total points.

Turn OFF randomize/shuffle question order. Do not use one-question-per-page. The 21 questions must remain in order so each one fills its matching contact-time, peak-force, average-force, or compliance slot.

Step 3: Build, upload, and preview

  1. After any change to usga-golfclub-ct-test.html, run node unit-ApplicationFiles/unit-3/lesson-2/build-buzz-template.js from the repository root. The generator preserves the original simulation graphics and replaces only the in-page SCORM quiz with Buzz slots.
  2. Upload the exact file u3l2-golf-club-ct-buzz-assessment-template.html.
  3. Open u3l2-golf-club-ct-buzz-assessment-template-preview.html locally first.
  4. Confirm that it contains 21 question slots and that the selected face changes the graph.

The template needs no hosting. If Buzz strips inline scripts, use the standalone usga-golfclub-ct-test.html as an external practice fallback, but retain the native Buzz questions for scoring.
