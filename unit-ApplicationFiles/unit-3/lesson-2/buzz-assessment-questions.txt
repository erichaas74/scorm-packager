Buzz Assessment Questions: Unit 3 Lesson 2 - Newton's Spacewalk Momentum Choice Lab

Assessment setup
- Student opens the hosted Newton's Spacewalk Momentum Choice Lab from the Buzz directions.
- Student completes both built-in levels and records the object choice, final velocity, arrival time, and docking speed.
- Suggested total: 12 points.

Question 1: Level 1 Correct Choice
Type: Multiple choice or short answer
Points: 1
Prompt: In Level 1, which object and throw speed gets the astronaut back to the airlock safely?
Teacher note: Correct answer is Choice C, Radar Dish at 3.2 m/s.

Question 2: Level 1 Velocity After Throw
Type: Numeric response
Points: 1
Prompt: For the correct Level 1 choice, what is the astronaut's speed after the throw? Enter the speed in m/s.
Teacher note: Correct answer is 1.00 m/s left. If using numeric only, accept 1.00 m/s.

Question 3: Level 1 Arrival Time
Type: Numeric response
Points: 1
Prompt: For the correct Level 1 choice, how long does it take the astronaut to reach the airlock?
Teacher note: Correct answer is 20.0 s.

Question 4: Level 2 Correct Choice
Type: Multiple choice or short answer
Points: 1
Prompt: In Level 2, which object and throw speed reverses the astronaut's drift and docks safely?
Teacher note: Correct answer is Choice D, Gold Bar at 2.4 m/s.

Question 5: Level 2 Velocity After Throw
Type: Numeric response
Points: 1
Prompt: For the correct Level 2 choice, what is the astronaut's speed after the throw? Enter the speed in m/s.
Teacher note: Correct answer is 0.95 m/s left. If using numeric only, accept 0.95 m/s.

Question 6: Level 2 Arrival Time
Type: Numeric response
Points: 1
Prompt: For the correct Level 2 choice, how long does it take the astronaut to reach the airlock?
Teacher note: Correct answer is about 21.1 s.

Question 7: Mission Evidence
Type: File upload
Points: 2
Prompt: Upload a screenshot showing one successful mission result with the selected choice, mission data, and success feedback visible.
Grading guide: Full credit if the screenshot clearly shows the level, chosen object, throw speed, final speed, and success message.

Question 8: Momentum Rule
Type: Essay
Points: 2
Prompt: Explain how throwing an object changes the astronaut's velocity. Use the momentum rule from the lab in your explanation.
Grading guide: Full credit explains that the astronaut changes velocity in the opposite direction of the thrown object and that object mass and throw speed determine the size of the change.

Question 9: Too Slow vs. Too Fast
Type: Essay
Points: 2
Prompt: Choose one incorrect option from either level and explain why it failed. Was it too slow, too fast, or the wrong direction?
Grading guide: Full credit names a specific choice and uses speed, arrival time, or safe docking speed as evidence.
