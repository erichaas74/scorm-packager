Lab Format Suggestions: Unit 3 Lesson 1 - PhET Forces and Motion Lab

Current fit for the new Buzz format
- Strong fit for the Galileo-style workflow because PhET can be linked or embedded and Buzz can own the evidence upload plus written responses.
- Static Tension Practice has been removed from this lesson. Unit 3 Lesson 1 should now point students to PhET Forces and Motion: Basics.
- The activity is observation based, so Essay/Short Answer questions with BusyBee grading guides are better than strict numeric auto-grading.

Suggested changes before publishing
1. Use the Buzz upload template so students see the PhET link, lab directions, and native Buzz questions together.
2. Keep the official PhET direct simulation link in the directions: https://phet.colorado.edu/sims/html/forces-and-motion-basics/latest/forces-and-motion-basics_all.html
3. Use the embedded PhET sim if Buzz allows it, and keep the external launch button as the fallback.
4. Require one screenshot upload from the Net Force screen with Sum of Forces, Values, and Speed turned on.
5. Consider adding a second optional screenshot from the Motion screen if teachers want stronger evidence for Part 2.
6. Use Essay questions for the Newton's Law explanations so BusyBee can grade reasoning.
7. Remove old Static Tension labels from menus, manifests, and packages before publishing.
8. If this lesson is still packaged as SCORM, point the manifest to index.html instead of the removed Static-Forces.html file.
