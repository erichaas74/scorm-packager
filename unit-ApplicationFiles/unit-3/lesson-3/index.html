Friction Force Lab

Pull a block with a spring scale, complete a traditional lab data chart, calculate static and kinetic friction coefficients, and use the evidence in your Buzz lab write-up.

Lab Procedure

How to complete this lab

  1. Use the Lab Data Chart row buttons to load each required trial.
  2. Click Constant Velocity Pull. The pull slowly grows to a peak, the block breaks loose, then it slides at constant velocity.
  3. Try each Constant Force Pull (Low, Medium, High) and compare the motion on the graph and the velocity meter. Which pulls make the block move? Why not all of them?
  4. Read the peak static force and the sliding kinetic force from the graph, then enter both values in the chart.
  5. Repeat until every chart row is complete, including the Wood +5 kg trial and Unknown A.
  6. Use Copy Chart for Buzz or a screenshot of the chart as evidence for the lab write-up questions. Show Hint marks the graph forces if you get stuck.

Hint: The dashed red line marks the static friction peak. The dashed green line marks the kinetic sliding force. The hint also shows the normal force and weight vectors on the block. Calculate mu_s = peak force / normal force and mu_k = sliding force / normal force. Adding mass increases normal force, so the friction forces should increase, but the coefficient for the same material should stay about the same.
