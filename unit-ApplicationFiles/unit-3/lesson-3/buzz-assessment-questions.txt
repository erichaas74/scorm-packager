Buzz Assessment Questions: Unit 3 Lesson 3 - Friction Force Lab

Assessment setup
- Student opens the hosted Friction Force Lab from the Buzz directions.
- Student runs the Constant Velocity Pull for required surfaces, reads peak static force and sliding kinetic force from the graph, and calculates coefficients of friction.
- Suggested total: 12 points.

Question 1: Wood Normal Force
Type: Numeric response
Points: 1
Prompt: For the Wood block, calculate the normal force. The mass is 5.0 kg. Enter the normal force in newtons.
Teacher note: Fixed answer is about 49.1 N.

Question 2: Wood Peak Static Force
Type: Numeric response
Points: 1
Prompt: From the Wood force-time graph, record the peak static friction force in newtons.
Teacher note: Fixed value is about 20.6 N.

Question 3: Wood Kinetic Sliding Force
Type: Numeric response
Points: 1
Prompt: From the Wood force-time graph, record the constant sliding kinetic friction force in newtons.
Teacher note: Fixed value is about 12.3 N.

Question 4: Wood Coefficient of Static Friction
Type: Numeric response
Points: 1
Prompt: Calculate mu_s for Wood using mu_s = peak static force / normal force.
Teacher note: Fixed answer is 0.42.

Question 5: Wood Coefficient of Kinetic Friction
Type: Numeric response
Points: 1
Prompt: Calculate mu_k for Wood using mu_k = sliding force / normal force.
Teacher note: Fixed answer is 0.25.

Question 6: Unknown A Data
Type: Short answer
Points: 2
Prompt: For Unknown A, record the normal force, peak static force, sliding kinetic force, mu_s, and mu_k.
Teacher note: Fixed values are normal force 49.1 N, peak static 27.0 N, sliding kinetic 17.2 N, mu_s 0.55, and mu_k 0.35.

Question 7: Graph Evidence
Type: File upload
Points: 2
Prompt: Upload a screenshot of a completed force-time graph with the selected surface visible. The screenshot should show the peak static region and the constant sliding region.
Grading guide: Full credit if the graph and selected material are readable and the relevant force levels can be checked.

Question 8: Static vs. Kinetic Friction
Type: Essay
Points: 2
Prompt: Use your graph evidence to explain how static friction differs from kinetic friction.
Grading guide: Full credit explains that static friction rises to a maximum before motion begins, while kinetic friction is the smaller force needed to keep the block sliding.

Question 9: Constant Force Pulls
Type: Essay
Points: 1
Prompt: In the Constant Force Pull tests, why can one pull fail to move the block while a stronger pull makes it speed up?
Grading guide: Full credit connects the low pull to not exceeding maximum static friction and the stronger pull to producing a net force after the block breaks loose.
