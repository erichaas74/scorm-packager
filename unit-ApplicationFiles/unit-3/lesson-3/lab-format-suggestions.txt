Lab Format Suggestions: Unit 3 Lesson 3 - Friction Force Lab

Current fit for the new Buzz format
- Strong lab for data collection because students read graph values and calculate coefficients.
- The current lab does not yet provide a student notebook or exportable data table, so Buzz submissions may rely on screenshots and manual transcription.

Suggested changes before converting the lab page
1. Add a Lab Data table with one row per material:
   - material
   - mass
   - normal force
   - peak static force
   - constant sliding force
   - mu_s
   - mu_k
2. Add student input fields for graph-read values before revealing/checking the official values.
3. Add a "Download Evidence Image" button that captures the graph, selected material, and data table.
4. Add a "Copy values for Buzz" button after a material row is complete.
5. Add a fixed Buzz-required set of materials, such as Wood and Unknown A, so the assessment stays focused.
6. Delay or gate the Show Hint feature until after students attempt to read the graph.
7. Add a final completion message: "Return to Buzz and answer the assessment questions."
8. Preserve collected rows when switching materials so students do not lose their data.
