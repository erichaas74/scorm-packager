Unit 5 PhET Buzz Question Banks

Each bank follows the Unit 3 application pattern:
- Evidence upload first
- Guided simulation observations
- Short conceptual explanations with BusyBee grading guides
- Final synthesis response
- 20 points total per lesson

Suggested simulations
Lesson 1: Wave on a String + Wave Interference
Lesson 2: Wave Interference (Sound) + Fourier: Making Waves
Lesson 3: Molecules and Light + Blackbody Spectrum
Lesson 4: Radio Waves & Electromagnetic Fields + Fourier: Making Waves
Lesson 5: Photoelectric Effect + Wave Interference + Bending Light + Color Vision + Alpha or Beta Decay

Important compatibility note
Radio Waves & Electromagnetic Fields, Photoelectric Effect, Alpha Decay, and Beta Decay may use legacy delivery depending on the current PhET version and student device. Test these in Buzz before publishing. If a legacy simulation will not run, replace it with an HTML5 alternative or teacher demonstration while keeping the questions conceptually similar.
