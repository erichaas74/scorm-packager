Unit 5 Buzz Assessment Instructions

Required setup, scoring, file map, and student-preview checks for all seven waves, light, and relativity application labs.

Common scoring contract

Every assessment is worth 15 points: 10 native auto-graded points followed by 5 BusyBee points. The final two questions are always evidence responses worth 2 and 3 points.

Evidence downloads are optional student records, not graded uploads. Students earn points through native Buzz calculations, concepts, and evidence-based explanations.

Across Unit 5 there are 59 questions and 105 points. Fourteen final responses use the authoritative BusyBee JSON rubrics.

Buzz setup workflow

  1. Create a new Buzz assessment with the lesson-specific title in its setup guide.
  2. Paste the entire matching _buzz_questions.txt file into Edit all questions.
  3. Confirm 15 total points: 10 automatically graded and 5 BusyBee.
  4. Upload the matching source HTML as the assessment template. Never upload the generated preview.
  5. Turn off question randomization/shuffling.
  6. Turn off one-question-per-page.
  7. Load the matching BusyBee rubric JSON if the domain does not preserve custom Meta- properties.
  8. Open student preview and complete the checklist below before publishing.

The ordered template slots and question import must stay paired. A randomized question order puts valid questions into the wrong lab sections.

Student-preview checklist

  1. The visible title matches the intended application.
  2. The simulation renders and every required control responds; Buzz has not stripped scripts.
  3. Every question appears in the matching labeled slot and the final two essays remain last.
  4. Numeric ranges and ordered multiple-choice answers grade correctly.
  5. The on-screen evidence table remains available while students answer the final responses.
  6. Optional evidence downloads work, but no question asks for an upload.
  7. Keyboard navigation, copy/paste, selection, and the context menu remain usable.
  8. Reset locally stored teacher-test progress so students begin with blank evidence.
