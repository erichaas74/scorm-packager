Grading design:
- Fixed numeric ready. All three cases are hard-coded (z = +0.12 hydrogen, -0.09 calcium,
  0 helium) and the readout tracks the longest-wavelength line of the matched element, so
  every student measures against the same rest wavelength.
- Tolerances come from the sim's own alignment window, ALIGN_TOLERANCE_Z = 0.008:
    Object A: lambda-0 = 656.3 nm, dLambda = +78.8 nm, accepted 73..84
    Object B: lambda-0 = 643.9 nm, dLambda = -58.0 nm, accepted -64..-52
    Object C: lambda-0 = 667.8 nm, dLambda =   0.0 nm, accepted -5.5..5.5
  Object C uses an explicit zero range because the default 1 percent tolerance of zero is zero.
- Q6 grades the derived recession speed in km/s rather than m/s, so students type 36000
  instead of entering scientific notation into a Buzz numeric field.
- Q1 is the evidence upload; Q7-Q8 use manual essay grader guides (style A).
