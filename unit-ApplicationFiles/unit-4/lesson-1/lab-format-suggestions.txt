Lab Format Notes: Unit 4 Lesson 1 - Six Simple Machines Work Lab

Lab workflow
- Six adjustable machine animations: inclined plane, lever, wedge, wheel and axle, pulley, and screw.
- Every machine completes the same ideal job: move a 120 N load through 1.0 m for 120 J of output work.
- Each machine provides five values for one physical variable, such as ramp angle, fulcrum position, wedge slope, radius ratio, supporting ropes, or thread pitch.
- The page has six separate sections. Each section shows only one machine simulation, with that machine's two Buzz questions immediately below it.
- Students change one value at a time and calculate results for two contrasting settings per machine.
- Calculated IMA, input force, input distance, ideal input work, and relative load speed are not displayed; students derive them from the givens and formulas.
- The first question below each animation focuses on force and mechanical advantage; the second focuses on distance and speed.
- Questions 11 and 12 use the screw animation for evidence and then synthesize the pattern across at least three machines.

Physics model
- Output force = 120 N and output distance = 1.0 m for every test.
- Ideal output work = 120 N x 1.0 m = 120 J.
- IMA is set by machine geometry.
- Input force = output force / IMA.
- Input distance = output distance x IMA.
- Ideal input work = input force x input distance = 120 J.
- With input speed fixed at 1.0 m/s, relative load speed = 1 / IMA.
- Increasing IMA reduces required input force, increases input distance, and reduces output speed for the same input speed.

Machine-specific changes
- Inclined plane: decrease ramp angle to increase ramp length and IMA.
- Lever: move the fulcrum closer to the load to lengthen the effort arm and increase IMA.
- Wedge: use a thinner slope to increase IMA.
- Wheel and axle: increase the wheel-to-axle ratio to increase IMA.
- Pulley: increase supporting rope segments to increase IMA.
- Screw: decrease thread pitch to increase turns, handle distance, and IMA.

Teacher and BusyBee grading notes
- The 12 Buzz questions total 15 points.
- Questions 1-10 are automatically graded for 10 points.
- Questions 11-12 total 5 BusyBee points.
- A strong final response cites the screw plus two other machines, explains constant ideal work with force x distance, and connects greater IMA to slower output motion at the same input speed.

BusyBee scoring: Award points only in 0.5-point increments, including whole points, from 0 to the question maximum. Select a rubric-supported allowed score; never report hundredths such as 2.85/3. Do not average or percentage-scale rubric criteria into an off-grid score. A binary completion rubric still permits only 0 or full credit.
