Lab Format Notes: Unit 4 Lesson 1 - IMA and AMA Lab

Lab workflow
- Four machine levels: inclined plane, pulley, lever, and wheel and axle.
- Each level contains three guided configurations shown with the contextual machine graphics.
- Students run all three trials to acquire output force, input force, output distance, and input distance.
- The data table deliberately does not reveal IMA or AMA.
- Students calculate IMA and AMA for each setup and enter both values to the nearest hundredth.
- A setup is verified only when both calculations are within 0.05 of the modeled value.
- The machine level is complete only after all three setups are verified.
- The comparison summary then identifies the largest IMA, smallest input force, and consistent IMA-greater-than-AMA pattern.
- Standalone practice permits load mass and lift height changes before testing. Buzz assessment mode fixes them at 20 kg and 1.5 m.
- Saved practice progress and saved assessment progress use separate session-storage records.

Physics model
- Output force = mass x 9.81 m/s2.
- IMA = input distance / output distance.
- AMA = output force / measured input force.
- The modeled input force equals ideal input force plus a fixed friction term for that machine level.
- Because friction raises measured input force, AMA remains below IMA.
- Increasing IMA reduces required input force but increases required input distance.
- Inclined-plane IMA also equals ramp length / lift height.
- Pulley IMA equals the number of supporting rope segments.
- Lever IMA equals effort arm / effective load arm.
- Wheel-and-axle IMA equals wheel radius / axle radius.

Teacher and BusyBee grading notes
- The ten Buzz questions total 15 points.
- Ten points are automatically graded and five points use BusyBee-supported essay rubrics.
- Numeric questions use explicit tolerance ranges based on the fixed assessment dataset.
- A strong response cites calculated IMA, AMA, and measured input force, describes the force-distance tradeoff, and explains the effect of friction.
- Do not award full credit for claims that friction changes IMA; IMA comes from ideal geometry, while friction reduces AMA.
