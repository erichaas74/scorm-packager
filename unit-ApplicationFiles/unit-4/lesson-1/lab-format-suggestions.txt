Lab Format Notes: Unit 4 Lesson 1 - Simple Machine Challenge

Current lab format
- Buzz-native application lab with four independently accessible levels and eight assessment questions.
- Level 1 explores inclined-plane configurations, Level 2 compares pulley configurations, Level 3 compares lever-arm configurations, and Level 4 compares wheel-and-axle configurations.
- Each level keeps three guided configurations (Setups A, B, and C) visible side by side. Each setup's information card sits directly below its animation, and the shared control panel spans the page below all three setups.
- All four level tabs are available from the start. Students can switch levels at any time; switching during an animation safely stops that run, and completed results remain available when they return.
- One button starts the three animations together. Their different scaled durations make one setup finish while the others are still moving.
- Shared load mass, lift height, and input speed lock when the first animation starts. Friction is fixed across all three setups within a level so geometry is the comparison variable.
- The three animations use scaled durations based on the calculated task times, making the time difference visible without forcing students to wait through the full recorded duration.
- Each recorded setup includes geometry, input force, input distance, output distance, time, equal output work, actual work, IMA, AMA, efficiency, and power.
- The visible table, copied data, downloaded CSV, and discovery summary are scoped to the active level and never mix machine types.
- After every three-setup animation, on-screen questions ask what changed, how that simple machine helps, and why time and power differ even though output work is equal.

Physics model notes
- Output force = mg and ideal output work = mgh.
- IMA is determined by machine geometry. Ideal input force = output force / IMA.
- Friction is added to the ideal input force, so actual input work is greater than ideal work and efficiency stays below 100 percent.
- The ramp angle and length cannot vary independently while preserving the shared lift height, so the two controls are linked.
- The lever load position sets an effective output arm within the selected full output arm.
- Recorded task time equals input distance / shared input speed. On-screen animation duration is scaled for usability.

Teacher and BusyBee grading notes
- Student values vary with the chosen shared mass, height, and input speed. Grade each three-setup table for completeness, consistent units, and relationships rather than one fixed answer key.
- IMA should be greater than AMA when friction is present.
- Actual input work should be at least as large as ideal work; efficiency should not exceed 100 percent.
- A strong conclusion uses within-level evidence to explain that a configuration using less force requires more input distance and does not eliminate the energy required to raise the load.
- Do not ask students to rank inclined planes, pulleys, levers, and wheel-and-axle systems against one another.
- Suggested total is 25 points.
