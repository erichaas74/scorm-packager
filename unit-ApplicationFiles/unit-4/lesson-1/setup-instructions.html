Step 1: Create the Buzz assessment

  1. Create an assessment titled Unit 4 Lesson 1: Six Simple Machines Work Lab.
  2. Open buzz-assessment-questions.txt and paste the complete contents into the Buzz text editor or Edit all questions screen.
  3. Confirm that Buzz creates twelve questions worth 15 points: ten multiple-choice and two essay questions.
  4. Confirm the grading split is 10 automatically graded points and 5 BusyBee rubric-graded essay points.
  5. Keep the questions in their original order. Each <a:question></a:question> slot pulls in the next question.

Turn off question randomization. The template labels and slots are arranged in question order. Do not use one question per page.

Step 2: Upload the template

  1. Upload u4l1-simple-machine-buzz-assessment-template.html as the assessment template.
  2. No separate simulation resource is required; the complete lab is embedded in the template.
  3. Preview as a student and confirm there are six separate sections. Each section must show only its matching simulation, followed immediately by that machine's two native Buzz questions.
  4. Confirm that the simulations show the changeable value but do not display calculated IMA, force, input distance, work, or speed answers.

Step 3: Student workflow

  1. Use the shared givens: output force is 120 N, output distance is 1.0 m, and comparison input speed is 1.0 m/s.
  2. Work down the page through the inclined plane, lever, wedge, wheel and axle, pulley, and screw sections.
  3. In each section, change the machine value and compare the two settings named in the questions.
  4. Use the provided machine relationship and ideal-machine formulas to calculate IMA, input force, input distance, work, and output speed.
  5. Answer the two questions directly beneath that simulation before moving to the next machine.
  6. Use the coarse and fine screw calculations plus two other machines as evidence in the final two BusyBee responses.

Validation notes

  • The six animations are adapted from problem-walkthoughs/unit 4/simple-machines.html, including the wedge and screw animations.
  • Students calculate ideal work using input force x input distance; the simulation does not show the result.
  • Increasing IMA reduces input force and increases input distance.
  • At the same input speed, relative load speed is 1 / IMA, so greater IMA produces slower output motion.
  • The simulation supplies only the selected physical value and fixed givens needed for student calculations. Native Buzz questions determine the score.
  • Use the local preview before uploading to verify all six two-question groups. If Buzz strips inline scripts, host index.html and embed or link it while keeping the native Buzz questions in the assessment.

BusyBee scoring increments

BusyBee scoring: Award points only in 0.5-point increments, including whole points, from 0 to the question maximum. Select a rubric-supported allowed score; never report hundredths such as 2.85/3. Do not average or percentage-scale rubric criteria into an off-grid score. A binary completion rubric still permits only 0 or full credit.
