Buzz Setup: Unit 4 Lesson 1 Simple Machine Challenge

Package contents

  • index.html: standalone lab for local or hosted testing.
  • u4l1-simple-machine-buzz-assessment-template.html: self-contained Buzz assessment template.
  • u4l1-simple-machine-buzz-assessment-template-preview.html: local preview showing question placement.
  • buzz-assessment-questions.txt: eight Buzz-native questions worth 25 points.

Step 1: Create the Buzz assessment

  1. Create an assessment titled Unit 4 Lesson 1: Simple Machine Challenge.
  2. Open buzz-assessment-questions.txt and paste the complete contents into the Buzz text editor or Edit all questions screen.
  3. Confirm that Buzz creates eight questions worth 25 points: seven essay questions and one multiple-choice question.
  4. Keep the questions in their original order. Each <a:question></a:question> slot pulls in the next question.

Turn off question randomization. The template labels and slots are arranged in question order. Do not use one question per page.

Step 2: Upload the template

  1. Upload u4l1-simple-machine-buzz-assessment-template.html as the assessment template.
  2. No separate simulation resource is required; the complete lab is embedded in the template.
  3. Preview as a student and confirm all four level tabs are immediately available; three side-by-side animations with one matching card below each; the shared control panel below the setup row; the level-specific data table; reflection prompts; Copy table for Buzz; and eight native questions.

Step 3: Student workflow

  1. Choose the shared load mass, lift height, and input speed.
  2. Begin with Level 1 and predict how the steep, medium, and shallow inclined planes will differ.
  3. Review the three side-by-side setups and their matching cards, then choose Animate all 3 setups. Shared task values lock when the simultaneous animation begins.
  4. Use the level comparison to explain what changed, how the machine helps, and why equal-output-work setups have different time and power.
  5. Use the tabs to move freely among inclined planes, pulleys, levers, and wheel-and-axle setups. Students may switch even while a comparison is running; that run stops safely, while previously completed level results are preserved.
  6. Copy each level-specific table into its matching Buzz question or use that level's CSV as backup evidence.
  7. Use only same-machine comparisons in all calculations, analysis, and conclusions. Do not rank different machine types.

Validation notes

  • The ramp length and angle are linked so every ramp trial reaches the selected shared height.
  • Ideal work is mgh for every configuration of the shared lifting task. Friction adds to input force and makes actual input work larger.
  • The displayed animation duration is scaled from each setup's calculated time. Recorded time uses input distance divided by the selected input speed.
  • All three setups in a level have equal output work because they lift the same mass through the same height. Geometry changes input force and distance, producing different time and power values.
  • Use the local preview before uploading to verify question placement. If Buzz strips inline scripts, use index.html as a hosted fallback.
