Lab Format Notes: Unit 4 Lesson 5 - Water Bottle Thermal Test

Current lab format
- Buzz-native, self-contained fixed-trial thermal-transfer investigation.
- The four trials hold water mass (0.50 kg), starting temperature (80.0 C), room temperature (22.0 C), and test duration (60 minutes) constant.
- Students run plastic with lid, single-wall metal with lid, vacuum-insulated with lid, and vacuum-insulated with the lid removed.
- Each trial produces the same temperature-versus-time values for every learner, so the numeric Buzz questions have fixed, explicit tolerance ranges.

Fixed reference values
- Plastic with lid: 80.0, 68.0, 59.0, 52.0, 48.0 C at 0, 15, 30, 45, and 60 minutes.
- Single-wall metal with lid: 80.0, 62.0, 51.0, 43.0, 39.0 C.
- Vacuum-insulated with lid: 80.0, 77.0, 75.0, 73.0, 72.0 C.
- Vacuum-insulated with lid removed: 80.0, 73.0, 69.0, 66.0, 64.0 C.
- For Question 5, Q = mc delta T = (0.50 kg)(4.186 kJ/(kg C))(72.0 C - 80.0 C) = -16.744 kJ.

Publishing notes
- The template includes the required clipboard and context-menu restriction script.
- Do not add a formula or calculation walkthrough to the Buzz template; students must supply Q = mc delta T from instruction.
- If Buzz strips the embedded script, host this complete template as a standalone web page and provide a teacher-approved external link; do not simplify the fixed trial graphics.
