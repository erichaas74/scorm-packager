Buzz Setup: Unit 4 Lesson 2 Which Track Is Fastest?

Package contents

  • index.html: standalone four-track race.
  • u4l2-track-race-buzz-assessment-template.html: self-contained Buzz template.
  • u4l2-track-race-buzz-assessment-template-preview.html: local question-placement preview.
  • buzz-assessment-questions.txt: eight questions worth 25 points.

Step 1: Create the assessment

  1. Create an assessment titled Unit 4 Lesson 2: Which Track Is Fastest?.
  2. Paste the complete contents of buzz-assessment-questions.txt into the Buzz text editor or Edit all questions screen.
  3. Confirm eight questions worth 25 points: seven essay questions and one multiple-choice question.
  4. Keep the original order so each native question loads into its matching template slot.

Turn off question randomization. Do not use one question per page.

Step 2: Upload the template

  1. Upload u4l2-track-race-buzz-assessment-template.html as the assessment template.
  2. No separate simulation resource is required; the race is embedded in the template.
  3. Preview as a student and confirm prediction buttons, all six controls, four timers, speed markers, energy bars, curved-track vectors, slow motion, replay, results table, and eight Buzz questions appear.

Step 3: Student workflow

  1. Predict the fastest track and record the shared settings.
  2. Release all carts, inspect the timers, marker speeds, energy bars, and vectors, then copy the result table.
  3. Rerun at least two controlled comparisons involving mass, friction, rotational inertia, or dip depth.
  4. Use the evidence to answer the energy, timing, variable, and conclusion questions.

Validation notes

  • The tracks use numerical path integration rather than preset animation timing.
  • Frictionless final speeds match because all carts share start and finish heights.
  • The model treats the inertia setting as I/(mr^2) and includes translational plus rotational kinetic energy.
  • Friction is modeled as rolling resistance along path length, so longer tracks lose more energy.
  • If Buzz strips inline scripts, use index.html as a hosted fallback.
