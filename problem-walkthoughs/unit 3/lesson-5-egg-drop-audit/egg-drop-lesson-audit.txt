CONFIRMED FINDINGS AND TARGETED FIXES

1. The opening assigns the wrong design context.
"Turning Physics into Protection" asks students to protect car passengers. Replace it with the actual raw-egg challenge, the teacher-assigned height, and the evidence students must submit. Keep a car crumple-zone comparison only if it directly explains the egg's cushioning.

2. The required calculation is not taught.
The project template requires v = sqrt(2gh), including height, substitution, result, and units. The Rise section does not teach this procedure. Add one native Process walkthrough and one transfer problem with a different height. Put equations and calculations in text using native LaTeX. Every actual step should have a supporting diagram without repeating its step heading in the image.

3. The measurements need distinct names and endpoints.
Use h for the vertical drop before first ground contact. For an upright, nonrotating device, measuring from its lowest contact point at release to the landing surface gives that drop. Explain this is also the egg's vertical displacement before first contact if the egg stays fixed in the device during the fall.
Use c for the initial clearance between the lowest part of the egg and the device's lowest external contact plane. The assignment must specify these endpoints instead of "to the egg."
Use d only for actual stopping distance, if it is independently measured or supplied. Initial clearance c indicates available space; it does not establish how much the egg moves while stopping. A rigid platform can have large clearance and almost no useful crush travel. Do not substitute c for h or automatically use c as d.

4. Impact speed is presented as an exact result for all designs.
The template calls sqrt(2gh) the speed the device was moving. State the assumptions: release from rest, negligible air resistance, h is the vertical drop before the modeled impact. Call the answer an ideal predicted impact speed. A parachute can make the actual speed appreciably lower. Use the ideal result as a common baseline, not proof that a parachute failed or that its actual speed equals the calculation. Speed is a magnitude; if retaining the word velocity, include the downward direction.

5. The testing instructions imply unavailable equipment.
"What Collision Data to Collect" recommends peak force, stopping time, force sensors, and timers. Replace the required data with things students can actually obtain: height, egg clearance, design photo, test evidence, condition of the egg, deformation, landing orientation, and a specific observation. A handheld stopwatch cannot reliably measure a brief impact interval. Optional slow-motion analysis requires enough resolved frames and a clearly defined start/end. Do not require a made-up stopping time or impact force.

6. Too much repeated explanation, too little application.
The engineering-process introduction, process introduction, six-step process, and summary repeat the same sequence. Later, multiple accordion panels and a second process repeat "longer stopping time, lower force." Replace the generic design process with a compact build/test checklist. Replace the final safety-device process with a worked egg-impact comparison using supplied data. Merge the four impact accordions into one visual explanation and a practice question.

7. Force terminology and conditions need correction.
Delta p / Delta t is average NET force. Use F_net,avg = Delta p / Delta t. The claim that doubling stopping time halves force requires the same momentum change. The current question omits this condition, although its intended key is correct under that assumption.
The final process claims the force is less intense "at any given moment." A longer collision time with the same impulse establishes a smaller average net force, not a guaranteed reduction at every instant or in peak force. Teach average force and explain that local concentrated contact can still crack the shell.
If contact force is calculated for a vertically stopping egg, distinguish it from net force. With upward positive, F_contact,avg - mg = Delta p / Delta t. This correction can remain teacher/extension material so the main lesson stays simple.

8. Prototype claims are stronger than the evidence shown.
The caption calls the example student-built and says it meets the criterion of keeping the egg safe, but the section provides no test result for it. Verify provenance before calling it student work. Otherwise label it "illustrative design." Describe features as intended mechanisms and ask students what a test would need to show. A photograph alone cannot establish stopping time or survival.

9. Questions do not assess the project skills.
Both present questions repeat the same time/force principle. Keep one improved version and add measurement selection, numerical speed, ideal-versus-actual speed, fair testing, and evidence-based redesign. Use plausible misconception-based options and explanations. Avoid making every question a definition check.

10. Fair testing is stated too generally.
Hold release height, landing surface, release method, orientation, and egg size/condition comparable. Change one intended feature at a time when feasible. If changing material also changes device mass, record that limitation rather than pretending mass stayed constant. One successful test supports success under that test condition, not universal protection.

11. The project template needs small but important repairs.
- The six-page file jumps from Slide 5 to Slide 7. Rename the final page Slide 6 unless another page is deliberately added.
- Clarify the height and clearance measurements with a diagram.
- Change the speed sentence to "Ignoring air resistance, the predicted speed just before first contact is ... m/s downward."
- Change "What part slows the fall?" to "Does any feature slow the fall? If so, explain how." A parachute should not become an implied requirement.
- Strengthen the final slide prompts: cite a specific observation, identify the egg's momentum change, explain how cushioning affects collision time and average force, and propose a change tied to the observation.
- Preserve the requirement that students use evidence from their own physical test. Teacher illustrations or model data are examples and cannot replace student evidence.

12. Assignment versions need clear labels.
The local U3L5 application currently describes an Impulse Jump Lab, while the supplied files describe an Honors egg-drop project. Do not silently overwrite the jump lab, its assessment, or scoring. Position this Rise section as preparation for the egg-drop project and label the two activities distinctly wherever both remain assigned.

13. Small course-level copy correction.
The course overview says "conservation fo momentum." Correct to "conservation of momentum" during implementation. This audit focused on the design section, not a new full audit of the other two sections.

14. Connect the project carefully to momentum conservation.
The egg's momentum changes when it stops because the padding and Earth exert external forces on the egg. Do not say the egg alone conserves momentum during impact. Add a brief bridge from the earlier collision lessons: conservation depends on the chosen system, while the egg's own change in momentum is explained by net impulse. Do not add another long collision-conservation derivation to the project workshop.

PROPOSED LEARNER SEQUENCE

1. Your egg-drop challenge
One short paragraph plus a submission checklist. State that a broken egg still produces useful evidence and must be reported honestly. Do not promise a particular grade for survival or failure.

2. What protects an egg?
Three illustrated tabs, about 35-55 words each:
- Slow the fall: drag can reduce incoming speed.
- Lengthen the stop: cushioning/crumpling can increase stopping time for the same momentum change.
- Support the egg: secure it and distribute contact instead of allowing hard, concentrated impacts.
Define bottoming out as using up the cushioning travel and hitting a much harder stop. Include it visually, not as a long new vocabulary section.

3. Measure the correct distances
One labeled cross-section with h outside the falling device and c inside it. A separate before/after inset can show actual crush travel d without equating it to c. Add a measurement-selection MC question.

4. Worked example: predicted impact speed
Native four-step Process with a diagram each step; see worked example A below.

5. Try the calculation
One MC numerical problem, followed by one question about a parachute and the no-drag assumption.

6. What happens during the stop?
One short animation or paired diagram. Two identical eggs enter at the same speed and come to rest without rebound. One stops abruptly; the other compresses padding over a longer time. Show equal momentum change and different force-time profiles. Explain that these are model results, not measured force data for the student's device.

7. Worked example: compare stopping times
Native Process using supplied values. Connect the calculation directly to a design choice. See example B below. This is lesson practice, not a new requirement to measure students' own impact force.

8. Build and run a fair test
One compact checklist with a small setup diagram. Record evidence before disturbing the device after impact. Use an approved release location and a clear landing area; the lesson must not invent a drop height or ask students to climb to unsafe locations.

9. Read a sample test record
Clearly labeled fictional teaching data, not claimed student work:
A: 1.25 m; 3 cm egg clearance; thin pad; pad fully compressed; egg cracked.
B: 1.25 m; 5 cm egg clearance; thicker compressible base; upright landing; egg intact.
Ask what the observations support and what they do not prove. Several features changed and only one test per design is shown, so the record does not isolate a single cause or quantify force. A fairer follow-up holds other features constant and repeats the comparison where feasible.

10. Explain and improve
Give a short claim-evidence-reasoning model, then ask students to choose an improvement that addresses a described failure. Finish with the checklist matching the six presentation pages.

This sequence can use roughly 12-15 principal Rise blocks plus embedded checks. Target about 700-900 words of explanatory prose, with more of the reasoning carried by diagrams, calculations, and questions. These are authoring targets, not measured final totals.

Optional interactive practice, if desired: a simple "Same drop, different stop" model with fixed egg mass and incoming speed, and two or three supplied stopping times. Students predict which setup has the smaller average net force, run the comparison, and see the equal impulse areas. Label it as an ideal model. Do not invent a universal force threshold that makes an animated egg survive or break. Real failure also depends on contact area, orientation, shell condition, and the force profile. This interaction can replace the paired animation above rather than extending the lesson with another separate game.

WORKED EXAMPLE A: IDEAL SPEED
Practice setup: device released from rest, upright, h = 1.25 m to first contact, neglect air resistance.

Step 1. Identify the measured drop.
Text: h = 1.25 m; v_initial = 0; g = 9.8 m/s^2.
Image: release position and first-contact position connected by a vertical height arrow. No equation or repeated step heading in the image.

Step 2. Choose the model.
Text: v^2 = v_initial^2 + 2gh, so v = sqrt(2gh) for release from rest. This gives speed.
Image: gravity arrow and small no-drag model symbol.

Step 3. Substitute and calculate.
Text: v = sqrt(2(9.8 m/s^2)(1.25 m)) = sqrt(24.5 m^2/s^2) = 4.9497... m/s.
Image: the same device close to first ground contact, with a downward velocity arrow.

Step 4. Interpret.
Text: ideal predicted impact speed is about 4.95 m/s, directed downward. Drag may reduce the actual speed. This value is a prediction, not a video measurement.
Image: split view of the modeled fall and a device with a parachute, without claiming a measured numerical parachute speed.

WORKED EXAMPLE B: WHY STOPPING TIME MATTERS
Practice setup: identical 0.060 kg eggs approach at 5.0 m/s downward and stop without bouncing. Given stopping times are 0.020 s and 0.060 s. These times are supplied model data.

Step 1. Set directions and velocities.
Text: upward positive; v_i = -5.0 m/s and v_f = 0.
Image: identical eggs with equal downward arrows, then stationary eggs.

Step 2. Find momentum change and net impulse.
Text: Delta p = m(v_f - v_i) = 0.060(0 - (-5.0)) = +0.30 kg m/s. J_net = +0.30 N s upward for either egg.
Image: equal momentum-change arrows for the two designs.

Step 3. Compare average net force.
Text: F_A = 0.30/0.020 = 15 N upward. F_B = 0.30/0.060 = 5.0 N upward.
Image: paired model force-time rectangles with equal areas; label axes and distinguish average-force models from real force traces. Keep the numerical calculations in the text.

Step 4. Make the design decision.
Text: tripling stopping time reduces average net force to one third for the same momentum change. Cushioning must provide usable travel and avoid bottoming out. These values do not establish peak shell stress or guarantee survival.
Image: thin padding fully compressed beside padding with useful travel remaining.

SIX RECOMMENDED MC CHECKS

1. Height versus clearance
An upright device has 0.05 m of egg clearance and its lowest point is released 1.80 m above the floor. Which h belongs in the ideal speed calculation before first contact?
A 0.05 m; B 1.75 m; C 1.80 m [correct]; D 1.85 m.
Feedback: h is the distance the assembly falls before its bottom first reaches the floor. The internal clearance serves a different purpose.

2. Calculate speed
Released from rest through 1.80 m with negligible drag, what is the predicted impact speed?
A 3.53 m/s; B 5.94 m/s [correct]; C 17.64 m/s; D 35.28 m/s.
Feedback: sqrt(2 x 9.8 x 1.80) = sqrt(35.28) = 5.94 m/s. The quantity under the square root is speed squared.

3. Model versus observation
A parachute-equipped device falls more slowly than the ideal prediction. Best explanation?
A The egg lost mass; B g became zero; C upward air resistance reduced acceleration [correct]; D the calculation proves the test was invalid.
Feedback: the ideal calculation omits drag. Real drag can lower impact speed without invalidating the observation.

4. Time and net force
Two eggs have the same 0.30 N s change in momentum. One stops in 0.020 s and the other in 0.060 s. Their average net-force magnitudes are:
A 15 N and 5 N [correct]; B 5 N and 15 N; C 15 N and 15 N; D 0.006 N and 0.018 N.
Feedback: divide impulse by stopping time. Longer time gives smaller average net force for this fixed impulse.

5. Fair comparison
Which comparison best tests the effect of pad thickness?
A Change pad thickness, drop height, and landing surface; B hold height, egg condition, surface, release orientation, and other design features comparable while changing pad thickness [correct]; C compare different devices at unknown heights; D repeat a successful drop without recording any setup.
Feedback: control the other factors. Record any unavoidable mass or geometry changes as limitations.

6. Evidence-based improvement
The recording shows the egg stays secured, but the base compresses fully before the egg stops and the shell cracks. Which change best addresses the observed failure?
A Add decorative tape; B add a rigid spacer while keeping the same crush travel; C increase usable compressible travel while keeping the egg supported [correct]; D drop from a greater height to increase stopping time.
Feedback: the observation points to bottoming out. Extra empty height or decoration does not necessarily increase usable stopping travel.

MODEL FINAL EXPLANATION
Use a clearly labeled fictional example, not a response for students to copy as their own evidence:
"Our egg cracked in the 1.25 m test. The ideal predicted impact speed was 4.95 m/s. The video showed the base compress completely while the egg remained in its holder. The egg's downward momentum changed as it stopped. We infer that the base ran out of useful cushioning travel, producing a shorter stop than intended. We would increase the usable compressible travel and test again at the same height. We did not measure stopping time or force, so we cannot give a measured force value."
