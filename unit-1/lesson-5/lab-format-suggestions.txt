Lab Format Suggestions: Unit 1 Lesson 5 - Skydiving Motion Graphs

Current fit for the new Buzz format
- Hosted-lab-plus-Buzz-assessment fit.
- Students run a fixed skydiving graphing simulation, collect values, and answer native Buzz questions.
- The lab includes three fixed trials: spread fall, dive pose, and parachute at 10 seconds.
- A data table records terminal velocity, terminal-time estimate, maximum speed, landing speed, and total fall time.
- The lab includes Copy Values for Buzz and Download Evidence Image buttons.

Buzz setup
1. Host or upload sky-dive-lab.html.
2. Link to the hosted lab in the Buzz assessment directions or template.
3. Create the native Buzz questions from buzz-assessment-questions.txt.
4. Use loose numeric tolerances for recorded values because students may click Record Current Trial at slightly different graph moments.
5. Include the upload question only if you want screenshot evidence.

Remaining work before publishing
- Preview the lab inside Buzz and confirm the canvas runs in the Buzz frame.
- Decide whether to require the evidence image upload.
- If you need exact auto-graded numeric answers, lock the Record button to only save after each trial lands.
