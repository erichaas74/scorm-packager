Buzz Setup: Unit 1 Honors Rocket Launch Lab

What this activity is

This self-contained template keeps the original rocket, launch-pad, flight-view, minimap, and animation graphics unchanged. The native calculation entry card is hidden so Buzz owns the four calculation responses through Level 3. The template locks its mission to a = 20 m/s2, t = 2.5 s, and g = -10 m/s2 so every student sees the same givens and the numeric questions can grade consistently.

Level 4 remains an interactive performance challenge. A run visibly succeeds when its on-screen Status says Challenge cleared. Students use the Copy values for Buzz or Download Evidence Image control after their flight, then submit a screenshot and explain the Status using their displayed flight data. The evidence question, rather than a fixed numeric key, grades the student-dependent run.

Step 1: Create the questions

  1. Create a Buzz Assessment titled Unit 1 Honors: Rocket Launch Lab.
  2. Paste the entire contents of buzz-assessment-questions.txt into the Buzz text editor / Edit all questions screen.
  3. The import creates six questions worth 8 points: four numeric questions for Levels 1–3, one Level 4 evidence upload, and one Level 4 evidence-based essay.

Step 2: Upload the template

  1. Run node unit-1/lesson-honors/build-buzz-template.js after any source-lab change.
  2. Upload u1h-rocket-launch-buzz-assessment-template.html as the assessment template.
  3. The template has six <a:question></a:question> slots. Question order must remain exactly as imported.

Turn OFF randomize/shuffle question order. Do not use one question per page. Buzz fills template slots in display order, so either setting breaks the level-to-question alignment.

Step 3: Preview as a student

  1. Confirm the page title reads Unit 1 Honors: Rocket Launch Lab Assessment.
  2. Confirm the rocket flight view, launch pad, minimap, and animations draw and run. If Buzz strips the script or rejects the template size, host the full lab outside Buzz and use a hosted link or iframe; do not remove graphics.
  3. Confirm Q1–Q2 appear under Level 1, Q3 under Level 2, Q4 under Level 3, and Q5–Q6 under Level 4.
  4. Enter the four answer-key values and confirm each numeric question grades correct.
  5. Complete one Level 4 challenge and confirm its Status visibly reports either Challenge cleared or a miss, Copy values for Buzz copies the flight data, and Download Evidence Image downloads a readable PNG.
