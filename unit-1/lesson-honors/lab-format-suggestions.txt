Buzz Conversion Notes: Unit 1 Honors Rocket Launch Lab

Conversion completed
- `u1h-rocket-launch-buzz-assessment-template.html` is generated from the original lab source, with the complete existing graphics and animation code inlined.
- The template hides only the native calculation-input card. Four Buzz numeric questions now own the Level 1-3 calculation inputs.
- Buzz mode uses the fixed mission a = 20 m/s^2 and t = 2.5 s, producing burn height 62.5 m, burnout velocity 50.0 m/s, coast height 125.0 m, and predicted apex 187.5 m.
- Level 4 remains student-dependent. Its on-screen Status declares `Challenge cleared` on success; Buzz grades a completed-flight evidence upload and a short data-based explanation instead of a fixed numeric response.
- The template includes Copy values for Buzz and Download Evidence Image controls for the Recorded Flight Data panel.

Publishing workflow
1. Run `node unit-1/lesson-honors/build-buzz-template.js` after any change to index.html, style.css, or sim.js.
2. Run `node unit-buzz-template-conversion-files/build-buzz-template-previews.js` from the repository root.
3. Upload the unique template file named in setup-instructions.html.
4. Turn off Buzz question randomization and do not use one-question-per-page.
