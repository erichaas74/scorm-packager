Lab Format Suggestions: Unit 1 Lesson 5 - Rocket Launch Lab / Rocket Flight Stages

Current fit for the new Buzz format
- Strong simulation and calculation sequence, but the mission is randomized, so Buzz needs either evidence-based grading or a fixed mission mode.
- The finished flight data panel is already useful for screenshot upload.

Suggested changes before converting the lab page
1. Add a fixed "Buzz mode" mission so all students have the same burn acceleration and burn time if numeric Buzz grading is desired.
2. Add a Lab Evidence panel that lists:
   - burn acceleration
   - burn time
   - burn height
   - burnout velocity
   - coast height
   - predicted apex
   - actual max height
   - retro start height
   - retro start velocity
   - retro burn duration
   - landing velocity
   - total flight time
3. Add a "Download Evidence Image" button for the finished flight data panel.
4. Add a "Copy values for Buzz" button after the calculation and flight are complete.
5. Add an attempt code if missions remain randomized.
6. Add a final instruction after the finished flight screen: "Return to Buzz and answer the assessment questions."
7. If Buzz owns the grade, reduce the role of SCORM scoring to progress tracking only.
8. Fix text encoding issues before publishing so symbols and middle dots display cleanly.
