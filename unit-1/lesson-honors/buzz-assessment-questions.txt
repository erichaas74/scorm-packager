Buzz Assessment Questions: Unit 1 Lesson 5 - Rocket Launch Lab / Rocket Flight Stages

Assessment setup
- Student opens the hosted Rocket Launch Lab from the Buzz directions.
- Student records the mission givens, completes the burn/coast/apex calculation sequence, runs a flight, and uses the recorded flight data to answer Buzz questions.
- Suggested total: 12 points.
- Important teacher note: The current lab randomly selects a mission from several burn acceleration/time combinations. Use short answer/evidence grading unless a fixed Buzz mode is added.

Question 1: Mission Givens
Type: Short answer
Points: 1
Prompt: Record your mission givens: burn acceleration, burn time, gravity, and target apex height.
Grading guide: Full credit if all givens are included and match the uploaded evidence.

Question 2: Burn Height
Type: Short answer or numeric response
Points: 1
Prompt: Calculate the burn height using delta y = 1/2 a t^2. Enter the burn height in meters.
Grading guide: Full credit if the calculation matches the student's mission givens.

Question 3: Burnout Velocity
Type: Short answer or numeric response
Points: 1
Prompt: Calculate the burnout velocity using v = at. Enter the velocity in m/s.
Grading guide: Full credit if the calculation matches the student's mission givens.

Question 4: Coast Height
Type: Short answer or numeric response
Points: 1
Prompt: Calculate the coast height from burnout to apex using v^2 = v0^2 + 2a delta y with final velocity 0 m/s.
Grading guide: Full credit if the answer uses the burnout velocity and gravity correctly.

Question 5: Predicted Apex
Type: Short answer or numeric response
Points: 1
Prompt: Calculate the predicted apex height by adding burn height and coast height.
Grading guide: Full credit if the predicted apex equals burn height plus coast height.

Question 6: Flight Data Evidence
Type: File upload
Points: 2
Prompt: Upload a screenshot of the finished flight data showing actual burn time, burn cutoff height, burn cutoff velocity, max height, retro start data, landing velocity, and total flight time.
Grading guide: Full credit if the recorded flight data is visible and readable.

Question 7: Predicted vs. Actual Apex
Type: Essay
Points: 2
Prompt: Compare your predicted apex height with the measured max height from the flight. Were they close? Explain using your data.
Grading guide: Full credit includes predicted apex, actual max height, difference, and a reasonable explanation.

Question 8: Landing Velocity
Type: Short answer
Points: 1
Prompt: Record your landing velocity and state whether the landing was safe.
Grading guide: Full credit if landing velocity and safe/unsafe conclusion match the evidence.

Question 9: Retro Burn Reflection
Type: Essay
Points: 2
Prompt: Did you start retro burn too early or too late? Use retro start height, retro start velocity, retro burn duration, and landing velocity as evidence.
Grading guide: Full credit uses recorded data to justify whether the retro burn timing should be earlier, later, longer, or shorter.
