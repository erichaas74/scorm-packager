# Physics activity work

Before creating, rebuilding, restyling, or changing a learner-facing physics simulation or walkthrough anywhere in this repository, read:

1. `problem-walkthoughs/AGENTS.md`
2. `problem-walkthoughs/RISE-INTERACTIVE-WALKTHROUGH-GUIDE.md`
3. The activity's existing source and any adjacent design notes.

This applies to activities under `unit-ApplicationFiles` as well as `problem-walkthoughs`. Do not wait until adding an index link to read the instructions.

The visual is the main product. A simple interface and high-quality artwork are separate requirements. Removing interface clutter does not authorize replacing detailed artwork with crude icons, stick figures, plots, or a different activity. Preserve the established visual and interaction design; make the requested correction at its actual scope.

Do not make the user supervise every small edit or repeat established preferences. Inspect the rendered result yourself, including desktop and narrow screenshots. Functional tests alone do not establish visual quality. Do not claim Rise-hosted verification when only the local/extracted package was tested.

For the ambulance Doppler activity, read `problem-walkthoughs/unit 5/doppler-sound-design.txt`. Its canonical source is `problem-walkthoughs/unit 5/doppler-sound.html`; preserve the detailed visual, prominent explicit answer feedback held for three seconds, automatic advancement without a Next button, source/listener comparison, and case-specific positioning described there.
